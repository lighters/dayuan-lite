## 扩展用户令牌只读能力（0.5.0，2026-10-22）

基线为 main `82fb90da10db0069ee8419f02eca79cc5d6c19cd`，本次功能版本 0.5.0；Python 3.12.12、官方 wecom-cli 1.3.4（f9b2815）。使用现有用户授权状态，不升级全局 CLI、不复制或恢复旧凭据。业务调用仍由适配器使用临时空 CLI 配置和环境注入用户令牌，不使用既有 Bot 配置。

先用独立能力探测确认各领域令牌可读，再接入正式 `dayuan wecom` 与 `serve`。下表每组操作均分别经 CLI 独立进程和同一 stdio MCP 进程实际调用成功，返回 `source=wecom_cli_user_token`、`read_only=true`，两种入口均 stderr 为空。MCP 初始化报告版本 0.5.0。每次只读有限样本，不自动全量翻页。

| 能力/正式操作 | CLI 和 MCP 的真实结果 |
| --- | --- |
| `contact-search` | 已知人员搜索返回 1 人，含人员字段 |
| `calendar-list` / `calendar-get` | 有界时间窗返回 10 条日程；读取其中 1 条详情 |
| `mail-search` / `mail-get` | 搜索返回 3 封邮件；选择已读样本读取正文，单封 `errcode=0`，包含附件元数据但未下载附件 |
| `disk-list` / `disk-search` / `disk-get` | 最近文件返回 3 项；类型过滤搜索返回 1 项；读取一个文件元数据 |
| `doc-search`（`doc_types=["sheet"]`）/ `sheet-get` / `sheet-read` | 普通表格搜索返回 1 项、子表元数据 1 项；A1:C3 返回 3 行共 9 格，含非空值 |
| `smartsheet-sheets` / `smartsheet-fields` / `smartsheet-records` | 列出 7 个子表；字段抽样 1 项、记录抽样 1 行 |
| `smartsheet-query` | 结构化标题参数生成单条 SELECT，经 `--json` 提交；返回 1 行 1 列，数据为对象编码 |
